Rosters

Sync from ESPN

One-tap sync: rosters, scores and free agents

  1. Save the "Grab ESPN" bookmark once. Drag this button to your bookmarks bar: Grab ESPN On a phone: bookmark any page, edit that bookmark, rename it "Grab ESPN" and replace its address with the copied code.
  2. On any ESPN Fantasy page, tap the bookmark. Open ESPN It pulls the whole league plus every available free-agent and waiver player, skaters and goalies, and copies it all. In Chrome on Android, type "Grab ESPN" in the address bar and tap the bookmark there.
  3. Come back and import. If your browser won't let the page read the clipboard, long-press the box below, paste, then Import.
iPhone: bookmark does nothing? Use a Shortcut instead

If ESPN's page blocks bookmark scripts, the tap does nothing. A Shortcut runs the same grab through Safari's share sheet and isn't blocked that way. Not tested on a device yet.

  1. Copy the code.
  2. In the Shortcuts app, make a new shortcut named Grab ESPN. Add the action Run JavaScript on Web Page and paste the code over its placeholder text. Add Copy to Clipboard after it. Tap the info button, turn on Show in Share Sheet, and set it to accept Safari web pages.
  3. In Safari, open your ESPN Fantasy league page, tap Share, then Grab ESPN. Allow the site permission the first time. Use Safari itself, not the ESPN app. Then come back here and tap Paste & import.
No bookmark? League-only fallback
  1. Open your league data. Open league data
  2. Select all, copy, paste above, Import. This updates rosters, scores and the week, not the free-agent list (ESPN only serves that to its own pages, which is why the bookmark exists). Anyone rostered since is still dropped from the old list.
